# 我的健康手账

个人饮食与健康记录网页。网站地址（仅站点所有者可访问）：https://my-health-journal-1108.mauveclef1.chatgpt.site

## 功能

- 按日期记录餐食与摄入热量；可用每 100 克热量和食用重量自动计算。
- 搜索 124 种常见中文食物，也可切换到完整 USDA 英文库搜索 8,790 条食物。数值来自 [USDA Standard Reference 28](https://fdc.nal.usda.gov/download-datasets/) 的 ABBREV 数据（2016 年），主要用于估算。生熟状态、品牌、烹饪和调味可能使实际热量不同。
- 设置自己的每日摄入、饮水、活动和睡眠参考目标。
- 记录饮水、体重、活动与睡眠，查看近 7 天摄入趋势。
- 导出 JSON 备份，或导入备份恢复记录。

## 使用与数据

打开网站，先设置个人目标，再选择日期并添加餐食。在“常见中文”中搜索中文名称；需要更多食物时切换“完整 USDA（英文）”，输入至少两个英文字母，例如 rice、chicken、tofu。选择食物后，填写实际食用重量；也可以自行输入食物与包装标示热量。

记录保存在当前设备的当前浏览器中，不会自动同步到 GitHub，也不会在不同设备间同步。清除浏览器网站数据或更换设备前，请先导出备份。

本仓库是公开的，只存放网页源码和食物参考数据；请勿提交健康记录备份、密码或其他私人资料。网页提供日常记录工具，不提供医疗建议。
